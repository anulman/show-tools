# Replacement coupling verification contract

The previous collar is rejected. Its geometric checks did not establish assembly and removal after the **bare bar** was glued into the ball. No old C2 receipt or print bundle is a substitute for this contract.

| Operator requirement | Required evidence before a replacement passes |
|---|---|
| Every coupling attachment is reversible after glue | Exhaustive lifecycle model starts with immutable glued bare bar and every other component outside. Complete assembly reachable. Every reachable state can return to the original outside state. Include every nut, screw, insert, cover, receiver and pad in actual export inventory. |
| Only axial opening access after glue | Actual part and ordinary-tool insertion, operating and removal sweeps against bar and fixed base. No lateral tool access above root. Outside-module side work requires the complete affected module outside the ball. |
| Minimum custom tooling | Ordinary named tools, with physical envelopes. A custom fork, spanner or driver fails admission. Printed structural coupling components are permissible; unnecessary printed hardware substitutes require removal or a specific reason. |
| Unlimited continuous knob rotation | All moving coupling components co-rotate with bar and knob. Analytic axisymmetric containment relative to stationary box/hex/support proves clearance at **every** angle, for arbitrary revolutions. Angular sampling alone fails admission. Internal latch travel stops must rotate with the complete assembly. |
| Preserve Darren's fitted bar | Exact pinned raw STEP SHA-256, full 109.22 mm height, original OD 94.4613302 mm / outer insertion profile and far-end shell attachment. Preserve original debond voids and bottom entry after the detachable module is removed (operator-confirmed scope). Installed actuation need not leave the full straight extensions open. |
| Preserve known snug knob fit | Original bore 44.35475 mm, entry 45.94225 mm, blind depth 25.4 mm. These are source socket dimensions, not a measured knob diameter. Knob height about 25.4 mm. |
| Existing spinner mounting hardware | Stock hex AF 34.925 mm, thickness 6.35 mm, stationary mounting barrel estimate 28.575 mm. No additional device retaining nut. Hex-top to knob-underside gap must fit 4.7625–22.225 mm adjustment. Approximate ruler measurements remain approximate. |
| Knob grip | Off-the-shelf cut padded grip material, standard set screws and nuts. Actual screw travel, pad/shoe retention and access must be established. Release joint must permit grip service after glue. |
| Existing box installation | Hex secured before it becomes inaccessible. Actual keeper/hex operation and base closure included in at least one full installation order. Lifting box for underside service is allowed. Passive low-friction bearing does not retain rotating bar to box. |
| Human review | Three complete new mechanisms on the Disco page; no rejected collar. Actual fresh canvas capture verifies scene delivery. Old source and exports retained. No fabrication approval implied. |

Each candidate needs its own actor inventory, tool inventory, forward and reverse witness traces, source and artifact digests, dimension/clearance results, geometry evidence and a list of unresolved physical checks. Do not substitute a producer's success booleans for independent artifact checks. Do not omit hardware from collision checks or silently treat a failed Boolean operation as empty space.

The finite-state verifier proves the transition model within its finite domains (maximum 100,000 reached states); the CAD checker establishes geometric fidelity under the modeled tolerances and motions. Physical resin shrinkage, brittleness, thread life, clamping friction, load capacity, balance, glue compatibility and fit with the actual parts require physical validation. These cannot honestly receive a formal PASS from CAD alone.

## Negative controls

Before admitting a candidate, demonstrate failures for: a preinstalled receiver or nut; missing reverse/unlock action; above-root side access; custom tool; omitted exported hardware; altered source socket; shortened bar; blocked original channel; material crossing the continuous-rotation envelope; and modified proof/export file. Run controls on the real candidate and restore it before producing the final frozen receipt.
